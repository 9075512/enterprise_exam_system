# 卷面 v3.0 — 设计规范

> 在线考试系统 · 管理端全站 + 考试端 视觉重设计方案
> 状态：**方向稿**（高保真原型已可交互）· 日期：2026-10-14

---

## 1. 设计主张

> **这套系统本质是纸与墨。**

试卷、答题卡、成绩单、报表 —— 这个系统产出的每一件东西，本质都是**印刷品**。
所以视觉语言应当从印刷品里长出来，而不是从通用 SaaS 后台模板里抄。

三条推论，决定了后面所有细节：

| 推论 | 具体做法 |
| --- | --- |
| **权威感来自墨，不来自彩色** | 主色是墨黑 `#1A1917`，不是品牌蓝。主按钮是墨黑实心。 |
| **层次来自线，不来自影** | 用 1px 实线、底纹、左侧色条区分区块。阴影仅留给浮层。 |
| **数据要有分量** | 数字一律衬线体（Georgia）+ `tabular-nums`，能逐位对齐比较。 |

## 2. 与 v2.2「冷静蓝」的对立点

这是一次**推翻**，不是精修。四组直接对立：

| 维度 | v2.2（旧） | v3.0（新） | 为什么 |
| --- | --- | --- | --- |
| 主色 | 亮蓝 `#2563EB` | **墨黑 `#1A1917`** | 蓝色管理后台满街都是，没有辨识度，也压不住"考试/文书"的严肃性 |
| 页面底 | 冷灰蓝 `#F5F7FB` | **暖纸 `#F7F5F0`** | 管理端与答题页都是长时间盯屏场景，暖色显著降低视觉疲劳 |
| 圆角 | 8 / 10 / 14px + 柔和阴影 | **2 / 3 / 4px，几乎不用阴影** | 直角 + 实线更接近印刷品的硬朗；阴影会让密集表格发灰 |
| 强调 | 无（蓝即强调，到处都是） | **赭橙 `#B45309`，唯一且克制** | 强调色用得少才有效；有唯一强调色，才敢在别处彻底安静 |
| 数字 | 无衬线 | **衬线 + 等宽数字** | 成绩、用时、及格率要能上下对齐扫读 |

## 3. 设计 Token

完整可运行版本见原型 `index.html` 的 `:root`。落地时替换 `src/styles/variables.scss` 的对应区块。

### 3.1 纸（承载面）

```scss
$paper-0: #FFFFFF;  // 卡片面
$paper-1: #F7F5F0;  // 页面底
$paper-2: #EFECE4;  // 表头 / 凹槽 / 次级底
$paper-3: #E4E0D6;  // 深凹槽 / hover 底
```

### 3.2 墨（文字与线条）— 每档都标了实测对比度

```scss
$ink-900: #1A1917;  // 17.5:1 / 16.6:1  ✅ 主文字、主按钮底
$ink-700: #3D3B36;  //  9.9:1 /  9.4:1  ✅ 次文字、表格内容
$ink-500: #5F5B54;  //  6.5:1 /  6.2:1  ✅ 辅助文字、微标签、表头
$ink-400: #6F6B64;  //  5.3:1 /  4.9:1  ✅ 占位符、弱化文字（AA 下限档）
$ink-300: #A8A29A;  //  2.5:1 /  2.3:1  ⚠️ 仅图标 / 描边 / 禁用态，禁止承载正文

$line-strong: #1A1917;  // 表格表头下沿 —— 整套设计的签名动作
$line:        #D9D4C7;  // 常规分隔
$line-soft:   #E8E4DA;  // 弱分隔
```

> ⚠️ **`$ink-300` 是"图形档"不是"文字档"**。这是本次规范最容易踩的坑：它看起来像个浅灰文字色，但对白底只有 2.5:1。占位符必须用 `$ink-400`。

### 3.3 赭（唯一强调色）

```scss
$ochre:        #B45309;  // 5.0:1 ✅ 强调文字、图标、链接
$ochre-bright: #D97706;  // 图形/指示条（侧栏当前项色条、进度条、图表末端点）
$ochre-soft:   #FDF3E3;  // 浅底（选中行、当前项、警示底）
$ochre-line:   #E8C99B;  // 描边
```

**该用**：导航当前项左侧 3px 条、选中行底、焦点外圈、关键数字、待处理计数、需注意提示。
**不该用**：整片按钮底色、装饰渐变、区块背景、语义状态（那是下面四个的活）。

### 3.4 语义（收敛为土调，与纸面共处）

全部 ≥ 4.5:1，**可以承载正文**，不需要旧版那种"底/描边/文字三件套"的复杂约束：

```scss
$ok:   #2F6F4E;  $ok-soft:   #EDF5F0;  $ok-line:   #C6DCCF;   // 6.0:1
$warn: #A16207;  $warn-soft: #FBF3E2;  $warn-line: #E8D5A8;   // 4.9:1
$err:  #A32C2C;  $err-soft:  #FAEFEE;  $err-line:  #E5C3C0;   // 7.1:1
$info: #3A5A78;  $info-soft: #EEF3F7;  $info-line: #C7D6E2;   // 7.2:1
```

> `$warn` 对纸底 4.5:1，是**贴着线**的，后续不得再调浅。

### 3.5 分类色（题型编码 — 唯一允许的多色场景）

只编码题型，不表达状态，不外溢到列表/表单/侧栏（延续旧版 §2.5 的例外原则）：

```scss
$type-single:   #3F5E7A;  // 单选 · 墨蓝
$type-multiple: #8C5A2B;  // 多选 · 赭褐   ← 替代 v2.2 的 violet #7C3AED
$type-judge:    #3F6B52;  // 判断 · 松绿
$type-blank:    #6A4C7C;  // 填空 · 紫棠
$type-essay:    #8C3A3A;  // 简答 · 砖红
```

白字放上去后的对比度依次为 6.8 / 5.8 / 6.1 / 7.2 / 7.6 : 1，全部达标。

### 3.6 排版

```scss
$ff-sans:  'PingFang SC','Microsoft YaHei','Hiragino Sans GB',system-ui,sans-serif;
$ff-serif: Georgia,'Times New Roman','Songti SC',SimSun,serif;   // 数字、英文与登录页品牌标题
$ff-mono:  'SF Mono','Cascadia Mono',Consolas,monospace;
```

关键决策：**界面文字用无衬线，数字用衬线**。
产品界面内的标题、表格、表单一律无衬线 —— 不要用宋体做界面标题，低分屏渲染会毛刺，容易滑向"政府公文网站"的观感。
**唯一例外是品牌时刻**（登录页大标题、"让每一场考试都有据可查"这一句）：这里允许衬线中文，大字号 + 大留白下渲染无损，与"卷面"主题互相成全。衬线只出现在这两个地方，不可外溢。

| 角色 | 字号 | 字重 | 其他 |
| --- | --- | --- | --- |
| 页面标题 | 23px | 600 | `letter-spacing: -.012em` |
| 题干正文 | 16.5px | 500 | `line-height: 1.75` |
| 界面正文 | 13.5px | 400 | `line-height: 1.6` |
| 辅助说明 | 12.5px | 400 | `$ink-500` |
| 微标签 | 11px | 600 | `letter-spacing: .09em` + `uppercase` |
| 统计数字 | 衬线 34px | 400 | `tabular-nums` |
| 等宽数据 | 12px | 400 | 时间戳、IP、账号 |

### 3.7 几何 / 阴影 / 动效

```scss
$r-xs: 2px; $r-sm: 3px; $r-md: 4px; $r-full: 999px;  // full 仅头像与计数气泡

// 阴影只服务浮层：模态、下拉、抽屉
$sh-pop: 0 2px 0 rgba(26,25,23,.04), 0 10px 28px -8px rgba(26,25,23,.18);

$ease: cubic-bezier(.2,.8,.3,1);
$t-fast: 110ms; $t: 160ms; $t-slow: 240ms;   // 只做 opacity / transform，不做缩放弹跳
```

## 4. 标志性设计动作（差异化所在）

这五条是"一眼认得出是这套设计"的地方，落地时优先保证：

1. **表头下沿的 1px 墨色实线** — 表格从"圆角卡片里的软表格"变成"印刷表格"。一条线定生死。
2. **左侧 3px 色条** — 墨黑用于统计卡，赭橙用于侧栏当前项与选中行。全站统一用手法，不靠圆角/渐变/阴影。
3. **编号前缀** — `01 / 02 / 03` 衬线小字，用于页面标题、分组标题、答题卡题型分组。印刷品的页码感。
4. **衬线数字 + tabular-nums** — 成绩、及格率、用时、排名。竖着扫能对齐。
5. **深墨侧栏 + 暖纸内容区** — 唯一的深色面在侧栏，其余全部纸白。反差建立"工具感"。

## 5. 组件规格

| 组件 | 规格 |
| --- | --- |
| **按钮** | 高 34（小 28 / 大 42）· 内距 14 · 圆角 3px · 字重 500。主=墨黑实心，次=白底+1px `$line`，幽灵=透明+hover 底纹，危险=白底+砖红边+砖红字。焦点 `outline: 2px solid $ochre; offset: 2px` |
| **输入框** | 高 34 · 圆角 3px · `$line` 描边。focus = 描边转 `$ink-900` + `0 0 0 3px rgba(26,25,23,.06)` |
| **表格** | 表头 `$paper-2` 底 + 11px 大写 `$ink-500` + 下沿 1px 墨线 · 行高舒适 44 / 紧凑 34 · hover `#FAF8F4` · 选中 `$ochre-soft` · 行分隔 `$line-soft` |
| **标签** | 直角小方块（2px），非胶囊。底 `-soft` + 字 `原色` + 边 `-line` |
| **统计卡** | 白底 + 左侧 3px 色条（墨黑/赭橙/`$paper-3`）+ 衬线大数字 + 底部细线分隔的对比脚注 |
| **批量操作条** | 墨黑整条横贯 + 白字 + 反色按钮（延续 v2.1 范式，视觉改为墨黑） |
| **分页** | 当前页 = 墨黑底白字；其余白底 1px 线 |
| **侧栏** | 宽 240 · `#141412` · 项高 34 · 当前项 = 白字 + 左侧 3px 赭条 + `rgba(255,255,255,.075)` 底 |

## 7. 落地路径（从原型到 Vue + Element Plus）

原型是纯 HTML/CSS，落地时需要处理三件事：

### 7.1 Token 层
- 替换 `src/styles/variables.scss` 的颜色区块（管理端 + 练题端全部）
- 同步 `src/constants/theme.ts`（ECharts / 内联 style 要用）
- 同步 `practice-web/src/styles/variables.scss`

### 7.2 Element Plus 主题层（关键，最容易漏）
`src/styles/element/index.scss` 里的 `$colors.primary.base` 必须改为 `#1A1917`，
否则 EP 的按钮/开关/分页还是旧的蓝，会出现**两个主色**并存 —— 这正是 v2.2 审计时踩过的坑（当时练题端的 EP 主色写着管理端 `#2563eb`）。
另外 EP 的默认圆角（`$border-radius`）要从 4px 降到 3px，与整体对齐。

### 7.3 样式护栏测试
项目已有 `styleGuard.test.ts`（反查式断言）。本次规范需要新增：

| 断言 | 内容 |
| --- | --- |
| 主色唯一 | 业务层禁出现 `#2563EB` / `#1d4ed8` / `rgb(29,78,216)` / `<svg>` 的 `fill="#…"` |
| 强调色唯一 | 只允许 `#B45309` / `#D97706` / `#FDF3E3` / `#E8C99B` 四个赭色值 |
| 直角约束 | 业务层 `border-radius` 不得出现 8px 及以上的字面量（`$r-full` 除外） |
| 阴影克制 | `box-shadow` 仅允许出现在浮层类文件中（`styles/` 与 dialog/drawer/popover 组件） |
| 灰阶合规 | `$ink-300` 不得作为 `color` 出现在业务层（只许作 border/fill/stroke） |

> 写护栏时注意项目已记录的坑：**扫描时要排除 `*.test.ts` 自身**，否则测试里的反例字面量会自命中。

### 7.4 建议的落地顺序
1. Token + EP 主题层（一次性切换，全站立刻变色 → 先看整体观感是否接受）
2. 基础组件：按钮 / 输入 / 表格 / 标签 / 分页（80% 的视觉收益来自这里）
3. 布局壳：侧栏 / 顶栏 / PageHeader
4. 高频页面：仪表盘 → 考试管理 → 成绩报表
5. 考试端：考生首页 → **答题页（重点）** → 成绩明细

## 8. 可访问性

全部文字档实测对白底 / 纸底均 ≥ 4.5:1（WCAG 2.1 AA 正文），详见原型第 ⑮ 页的实测表。

- **键盘**：全交互元素可达；焦点环统一 `2px $ochre` + 2px 偏移；表格行内操作 `:focus-within` 时显形
- **点击目标**：按钮 34px（小 28 / 大 42）、表格行 44px、答题卡格子 ≥32px
- **动效**：110/160/240ms，只做 opacity 与 transform，不做缩放弹跳
- **颜色不作唯一信号**：状态标签同时带圆点/文字，切屏异常行同时有底色与标签
