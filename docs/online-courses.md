# 在线看课与课程管理

学员入口：学习中心 → 在线看课（`/exam/courses`）。详情地址为 `/exam/courses/:courseId`，可通过 `?lesson=小节ID` 链接到指定小节。管理入口：教学资源 → 课程管理（`/admin/courses`）。

煤矿安全内容选课见[煤矿安全课程与视频资源（含出处）](coal-mine-safety-courses.md)，包含 8 组原站资源、发布机构、日期、原始链接及课程简介署名格式。

## 接入

- 课程和章节现在从后端 API 读取，管理员上架后学员可见，草稿、下架和已删除课程不可通过学员详情接口读取。课程初始为空；`src/data/courses.ts` 的示例仅作为测试数据，不作为加载失败时的回退。
- 已有环境执行 `npm --prefix server run db:migrate:courses`，仅幂等创建 `courses`、`course_media` 两张表，不运行历史种子、不重建数据、不改变权限。本地开发库已执行该迁移；新数据库的 `db:init` 会创建课程表。
- 新增菜单权限 key `course-manage`（仅管理员）、`courses`（学习角色），前后端及接口校验一致。新建数据库的内置角色默认授权；已有数据库需要管理员在“菜单权限”中勾选对应入口，重新登录后生效，个人例外权限仍生效。公网 `PRACTICE_ONLY` 实例不注册课程模块。
- 观看记录仍使用 `localStorage`，以 `course-progress:v1:账号ID` 隔离，按课程及小节记录位置、实际时长、完成状态和最后小节。当前不支持跨设备同步，清除浏览器数据会删除观看记录。

## 管理功能

- 课程新增、编辑、删除、关键词和状态筛选、分页、展示排序；可维护封面、标题、简介、分类、讲师、难度及演示标记。
- 新课程存为草稿。上架要求完整封面、简介、分类、讲师，每章至少一节且每节有视频；上架课程先下架才能编辑或删除。删除是软删除，已上传媒体不自动删除，避免破坏其他课程引用。
- 章节和小节支持增删、上下排序。保存以单行JSON原子更新章节树，版本号阻止并发覆盖；改标题和顺序保留ID，更换视频由服务端生成新小节ID，避免新视频沿用旧进度。已删除小节不计入当前完成数。
- 封面可上传JPG/PNG/WebP（8MB），视频可上传MP4/WebM（200MB），也可填写HTTP(S)资源地址。文件流式落盘，校验MIME、文件头与体积，失败清理文件。上传可取消，视频会尝试读取本机时长，也可手动维护展示时长。
- 管理播放预览可切换小节，不写学员进度；保存失败保留输入，未保存退出需确认，上传或保存期间锁定重复操作。并发冲突提供重新加载入口。
- 创建、编辑、上下架和删除记录审计日志。

## 存储与部署

- 文件位于 `<STORAGE_DIR>/course-media`，元数据在 `course_media` 表。部署应持久化并备份数据库及存储目录。
- 上传返回 `/api/courses/media/:id?t=...` 签名资源地址，方便原生视频和图片使用，支持Range/HEAD。资源签名依赖JWT_SECRET，需保持稳定；持有签名链接者可读取资源。下架控制课程入口，不撤回已分发资源链接，也不提供DRM。
- `deploy/nginx-exam.conf` 对课程上传单独设置201MB请求上限、流式代理及长传输超时，其他接口保持10MB。现有部署需合并该配置；外部网关也应满足大小与超时要求。
- 本功能不进行视频转码，资源需使用浏览器支持的编码。外链需可访问且支持Range；播放网络、编码或资源异常均在播放器提示重试。

## 播放规则

- 仅提供播放、暂停和页面全屏，固定 1.0 倍速；进度条只读，通过 `seeking`、`ratechange` 事件回退跳播及倍速变化。此为客户端交互限制，不用于防篡改或认证学时。
- 视频元数据加载后恢复位置，浏览器仍需用户点击播放。已完成小节再次打开从头播放，完成标记保留；仅视频自然播放结束才标记完成。点击其他小节不会自动标记前一小节完成。
- 播放时约每秒保存一次，暂停、页面隐藏、`pagehide`、卸载及切节时补存；补存携带原课程及小节 ID，避免切换时串写。
- 加载失败、20 秒加载超时及播放被浏览器阻止都有提示；重试保留当前位置。存储不可用或内容损坏时提供提示并保留本页可用状态。
- 1050px 及以下使用目录抽屉，支持点击遮罩及 Escape 关闭，选择小节后自动关闭；桌面端目录可展开及收起章节。
