# 在线看课与课程管理

学员入口：学习中心 → 在线看课（`/exam/courses`）。介绍地址为 `/exam/courses/:courseId`，学习地址为 `/exam/courses/:courseId/learn`。旧介绍地址携带 `?lesson=小节ID` 时兼容跳转学习页。管理入口：教学资源 → 课程管理（`/admin/courses`）。

煤矿安全内容选课见[煤矿安全课程与视频资源（含出处）](coal-mine-safety-courses.md)，包含 8 组原站资源、发布机构、日期、原始链接及课程简介署名格式。

## 接入

- 课程和章节现在从后端 API 读取，上架后仅学习范围内学员可见，草稿、下架和已删除课程不可通过学员详情接口读取。升级前的课程保留原有公开范围。课程初始为空；`src/data/courses.ts` 的示例仅作为测试数据，不作为加载失败时的回退。
- 已有环境执行 `npm --prefix server run db:migrate:courses`，幂等创建 `courses`、`course_media`、`course_categories`、`course_progress` 四张表并迁移已有课程分类，不运行历史种子、不重建数据、不改变权限。本地开发库已执行该迁移；新数据库的 `db:init` 会创建课程表。
- 新增菜单权限 key `course-manage`（仅管理员）、`courses`（学习角色），前后端及接口校验一致。新建数据库的内置角色默认授权；已有数据库需要管理员在“菜单权限”中勾选对应入口，重新登录后生效，个人例外权限仍生效。公网 `PRACTICE_ONLY` 实例不注册课程模块。
- 观看记录保存在 MySQL `course_progress`，按登录账号、课程及小节隔离，包含播放位置、实际时长、完成状态和最后选择的小节。同一账号换设备登录可续播；旧浏览器 v1 记录仅补充数据库中缺失的小节，不覆盖已有记录。v2 本地缓存暂存断网请求，恢复网络后重试；跨设备冲突以数据库记录为准并提示重新同步。

## 管理功能

- 课程新增、编辑、删除、关键词和状态筛选、分页、展示排序；可维护封面、标题、简介、分类、讲师、难度及演示标记。
- 课程分类使用下拉选择；课程管理顶部“维护分类”支持新增、改名、排序和删除。改名同步到关联课程，被使用的分类不可删除。
- 编辑抽屉的“课程详情”支持富文本、列表、链接与图片上传（单张2MB、最多10张，内容最多20000字符），服务端保存时清理不安全HTML；学员详情和管理预览显示富文本，列表仍使用简介。
- 新课程存为草稿。上架要求完整封面、简介、分类、讲师，每章至少一节且每节有视频；上架课程先下架才能编辑或删除。删除是软删除，已上传媒体不自动删除，避免破坏其他课程引用。
- 章节和小节支持增删、上下排序。保存以单行JSON原子更新章节树，版本号阻止并发覆盖；改标题和顺序保留ID，更换视频由服务端生成新小节ID，避免新视频沿用旧进度。已删除小节不计入当前完成数。
- 封面可上传JPG/PNG/WebP（8MB），视频可上传MP4/WebM（200MB），也可填写HTTP(S)资源地址。文件流式落盘，校验MIME、文件头与体积，失败清理文件。上传可取消，视频会尝试读取本机时长，也可手动维护展示时长。
- 未配置封面时，填写标题后可点击“生成封面”，根据标题、分类和讲师生成同款深色网格封面并立即预览，保存课程后生效。已有封面先清空地址再生成，避免覆盖上传图片；生成中禁用保存与重复操作，支持取消，失败保留输入。
- 管理播放预览可切换小节，不写学员进度；保存失败保留输入，未保存退出需确认，上传或保存期间锁定重复操作。并发冲突提供重新加载入口。
- 创建、编辑、上下架、删除及分类维护记录审计日志。

## 绑定科室和人员

课程管理每行的“绑定人员”可多选科室和单独指定人员，二者取并集并去重。选择父科室包含全部下级，科室成员及组织关系变化后自动更新；单独指定人员不受科室调动影响。仅启用中的考生账号纳入范围，学员仍须具备“在线看课”菜单权限。窗口显示生效名单预览，保存时再次校验科室和指定人员。

新课程先存草稿，必须设置非空绑定规则后才能上架。已上架课程可直接调整人员，无需下架；保存使用课程 revision 防止覆盖其他管理员的修改，并记录 `course.audience` 审计。空名单可以保存，表示无人可看，不会变成公开。停用或已删除的指定人员需先从选择中移除。

已有数据库执行 `npm --prefix server run db:migrate:courses`，为课程补充可空 `audience_json` 字段。SQL NULL 表示升级前的公开课程，迁移不改变状态、版本或观看记录，不运行历史种子，可重复执行。已有公开课程首次保存绑定后转为指定范围，界面会提示此变化。新建课程明确保存空绑定对象，不能借用 NULL 兼容规则公开。

课程列表、详情、观看记录读取、保存、切节及旧记录导入共享范围判定。人员被移出后不能再访问，播放器在同步收到 403/404 时停止播放与补传并提示返回课程列表；本机待补传记录清除，服务端历史记录保留，重新纳入后可恢复。媒体签名链接仍沿用现有资源读取机制。

## 后台学习进度与 Excel

课程管理每行的“学习进度”默认列出当前范围内所有人员，包含未看课人员；历史公开课程按全部启用考生统计。支持按姓名或账号、科室（含下级）、学习状态查询，分页和刷新。统计卡展示当前页签及筛选条件下的总人数、未开始、学习中、已完成与完成率。

人员进度按“完成的当前有效小节 / 当前有效小节总数”计算，保留一位小数。仅打开介绍或选择小节仍为未开始；有播放位置或完成记录为学习中，全部有效小节完成才为已完成；空课程进度为 0。已删小节不参与计数，更换视频生成的新小节不会继承旧记录。最近学习时间只取有实际播放数据的有效小节记录，空值显示为“—”；该字段与播放位置不代表认证学时。

“小节明细”展示当前各章各节的完成状态、播放位置、视频时长和最近记录。尚未加载过视频元数据的小节没有实际视频时长，界面显示“—”，导出为 0 秒。所有时间显示为北京时间。

“历史记录”页签展示已有记录但已不在当前范围的人员，包括调出、取消指定和停用人员，不计入当前名单的完成率；仍按当前课程有效小节统计。这里保留的是已有观看记录，不是历次绑定名单快照。账号永久删除仍沿用现有用户删除规则及数据库外键行为。

“导出 Excel”导出当前页签、已查询筛选条件下的全部匹配人员，不受分页限制。一个工作簿包含“人员汇总”和“小节明细”，两张表来自同一次数据库快照；汇总包含课程、姓名、账号、当前科室、人员范围、状态、完成数、总小节数、进度、最近学习时间，明细增加章节、小节、小节状态、播放位置、视频时长和小节最近记录时间。时间为北京时间，缺失时间留空，未开始人员也会导出；无人员时保留表头。

管理接口（均需管理员角色及 `course-manage` 菜单权限）：

- `GET /api/courses/manage/:id/audience`：返回 mode（public/assigned）、revision、departmentIds、userIds。
- `PUT /api/courses/manage/:id/audience`：提交 revision、departmentIds、userIds；版本冲突返回 409，非法科室或指定人员返回 400。
- `GET /api/courses/manage/:id/progress`：scope=current/history，keyword、departmentId、status（not_started/learning/completed）、page、pageSize；返回 list、分页、summary。
- `GET /api/courses/manage/:id/progress/:userId`：人员当前有效小节明细。
- `GET /api/courses/manage/:id/progress/export`：使用相同筛选条件返回 `.xlsx` 文件，忽略分页。

## 存储与部署

- 文件位于 `<STORAGE_DIR>/course-media`，元数据在 `course_media` 表。部署应持久化并备份数据库及存储目录。
- 上传返回 `/api/courses/media/:id?t=...` 签名资源地址，方便原生视频和图片使用，支持Range/HEAD。资源签名依赖JWT_SECRET，需保持稳定；持有签名链接者可读取资源。下架控制课程入口，不撤回已分发资源链接，也不提供DRM。
- `deploy/nginx-exam.conf` 对课程上传单独设置201MB请求上限、流式代理及长传输超时，其他接口保持10MB。现有部署需合并该配置；外部网关也应满足大小与超时要求。
- 本功能不进行视频转码，资源需使用浏览器支持的编码。外链需可访问且支持Range；播放网络、编码或资源异常均在播放器提示重试。
- 生成封面不依赖外部服务或新增运行时依赖：后端产生1280×720的SVG，写入同一媒体目录并返回签名地址。仅系统模板可创建SVG，上传接口仍拒绝SVG；用户文本转义，图片响应附带限制性CSP。

## 封面生成接口

`POST /api/courses/manage/cover`，需登录且具备管理员角色与 `course-manage` 菜单权限。

```json
{ "title": "矿用自救器佩戴", "category": "自救互救", "instructor": "安全培训中心" }
```

`title` 必填，最多120字符；`category`、`instructor` 可省略，最多50、80字符。成功返回统一响应 `{ code: 0, message, data: { id, url, mime: "image/svg+xml", size } }`，将 `data.url` 填入课程的 `cover`。生成接口只创建媒体，不自动保存或上架课程。短标题大字展示，长标题最多两行，超出以省略号显示，完整标题保留在图片元信息中。分类匹配水/通风、瓦斯/爆炸、煤仓/运输/机电时分别使用蓝、黄、橙色，其余采用绿色。

## 播放规则

- 仅提供播放、暂停和页面全屏，固定 1.0 倍速；进度条只读，通过 `seeking`、`ratechange` 事件回退跳播及倍速变化。此为客户端交互限制，不用于防篡改或认证学时。
- 视频元数据加载后恢复位置，浏览器仍需用户点击播放。已完成小节再次打开从头播放，完成标记保留；仅视频自然播放结束才标记完成。点击其他小节不会自动标记前一小节完成。
- 播放时约每秒暂存到本机、约每5秒同步数据库，暂停、结束、页面隐藏、`pagehide`、卸载及切节时立即补存；退出请求使用 keepalive，补存携带原课程和小节 ID。并发写入通过版本及客户端序号防止旧请求覆盖新记录，完成标记不会因重看而清除。
- 加载失败、20 秒加载超时及播放被浏览器阻止都有提示；重试保留当前位置。存储不可用或内容损坏时提供提示并保留本页可用状态。
- 1050px 及以下使用目录抽屉，支持点击遮罩及 Escape 关闭，选择小节后自动关闭；桌面端目录可展开及收起章节。

## 分类与观看记录接口

分类维护：`GET/POST /api/courses/manage/categories`、`PUT/DELETE /api/courses/manage/categories/:id`，使用课程管理权限；修改和删除需要 revision，分类重名及并发冲突返回409。

观看记录：`GET /api/courses/progress`、`PUT /api/courses/progress/:courseId/:lessonId`、`PUT /api/courses/progress/:courseId/selection`、`POST /api/courses/progress/import`。只允许读写当前登录账号、已上架课程的有效小节。进度写入携带 position、duration、completed、revision、clientId、sequence；来自其他设备的旧版本返回409。

## 先了解，再学习

课程卡片统一进入介绍页，展示封面、信息、完整富文本和章节目录；旧课程未填写图文则展示简介。简介超过三行可展开。浏览介绍、展开目录不改变最后观看小节，也不加载播放器；点击小节进入对应视频。开始学习进入第一有效小节，继续学习恢复最后有效小节，全部完成后再次学习从首节开始且保留完成标记。列表顶部继续上次学习直接进入学习页。

桌面介绍与目录双栏；1050px及以下改为介绍/目录页签和底部固定学习按钮，默认介绍，保留正文底部空间。移动考生导航在介绍页让位给学习按钮，返回入口始终可用。学习页保留播放器和目录，并提供返回课程介绍入口；无有效小节时介绍仍可查看，学习按钮禁用。
