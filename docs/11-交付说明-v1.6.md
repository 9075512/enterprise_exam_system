## 2. ① 防作弊与公平性

### 2.1 配置新增（`system_settings` →「考试规则」Tab）

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `cheatWatermarkEnabled` | bool | true | 答题页铺陈「姓名 + 账号」淡浮水印 |
| `cheatCopyGuardEnabled` | bool | true | 答题页禁用复制/剪切/右键/文本选择/拖拽 |

### 2.2 答题页行为（`ExamTakingPage`）

- **浮水印**：`pointer-events:none` 的全屏 `fixed` 覆盖层，斜排重复「姓名 账号」，`z-index` 介于吸顶栏与弹窗之间，不影响作答。
- **复制限制**：根容器绑定 `copy/cut/contextmenu/selectstart/dragstart` 守卫，仅在 `cheatCopyGuardEnabled` 开启时 `preventDefault`（响应式，无需手动绑定/解绑）。

### 2.3 切屏审查页

- 后端 `GET /api/records/cheat?examId=`（admin）：返回该考试「含切屏事件的已交卷记录」，附姓名/科室，按切屏次数降序（上限 500）。
- 前端成绩报表新增第 5 个 Tab「切屏审查」：汇总列表 + 展开行展示每条 `cheatEvents` 时间线（发生时间 / 离开秒数）。
- 实现要点：路由 `/cheat` 注册在 `/:id` **之前**，避免被参数路由抢先匹配。

## 3. ② 题型扩展与人工阅卷

### 3.1 题型与判分

- `questions.type` 扩 `fill`（填空，自动判分）、`short`（简答，人工阅卷）。
- 填空 `answer` = 文本数组（逐空参考答案）；自动判分：`trim` + 忽略大小写**逐空**匹配，全对才得分。
- 简答 `answer` = 参考答案文本；交卷后记录进 `pending_review`，客观题（含填空）先行计分。
- 判分唯一来源：`server/src/utils/grading.ts`（考试与练题共用）。

### 3.2 记录状态与阅卷流

- `exam_records.status` 增 `pending_review`；新增 `exam_records.subjective_scores`（JSON，主观题逐题得分）。
- 交卷：含简答题 → `pending_review`；客观题先出分并通知「待阅卷」。
- 阅卷：`GET /records/pending`（待阅卷列表，admin/author，先交先阅）+ `PUT /records/:id/review`（逐题 0~分值给分，重算总分 = 客观 + 主观，转 `submitted`，含阅卷完成通知）。

### 3.3 关键修复（本期内发现）

1. **补考次数口径**：`countSubmittedByExamAndUser` 补计 `pending_review`——否则含主观题的答卷交卷后仍可绕过 `maxAttempts` 再开新卷。
2. **错题率口径**：报表 `buildWrongRate` 排除简答题——否则简答恒被计为「答错」产生误导。

## 4. ③ 组织与权限精细化

### 4.1 多级科室树

- `departments` 增 `parent_id`（自引用），支持父子层级；用户、考试均可挂任意节点（叶子或中间节点）。
- **考试级联授权**：考试存「原始所选科室」，考生端用**祖先链**匹配——考生科室或其任一上级命中考试所选科室即视为参与，**选中父科室自动覆盖整棵子树**；发布通知同步展开子树覆盖。
- **防环**：禁止自引用、禁止挂到子孙节点；删除时存在子科室或归属用户 → 1005。

### 4.2 出题人题库授权

- 新增 `bank_authors` 映射表（`bank_id ↔ user_id`）；`BankDto` 增 `authorIds / authorNames`。
- 统一鉴权入口 `bankAuth`（`assertBankAccess / listAccessibleBankIds`），贯穿：
  - **题库**：列表隔离（author 只见授权库）、详情、增删改、试题迁移；
  - **试题**：列表 / 全局池 / 科目 / 增删改；
  - **导入**：预览 / 提交；
  - **试卷**：列表 / 详情 / 抽题 / 组卷 / 编辑（题源 + 卷源均校验）。
- admin 在题库表单维护「授权出题人」；author 新建题库自动授权自己；种子数据将演示出题人 `user-author` 授权到两个示例题库。

## 5. ④ 数据运营与审计

### 5.1 操作审计日志

- 新增 `audit_logs` 表（**自包含、无外键**——操作者/目标删除后日志仍可读），字段：`actor_id / actor_name / action / target_type / target_id / target_name / detail / created_at` + 4 个索引。
- 统一入口 `audit.service.record()`，**fail-open**（审计失败绝不阻断主业务）。
- 埋点贯穿关键写操作：**用户**（建/改/删/重置密码）、**考试**（建/改/删）、**题库**（建/改/删/迁移试题）、**菜单权限**（更新）。
- 查询：`GET /api/audit-logs`（admin）按动作/目标类型/关键字/时间范围过滤 + 分页。

### 5.2 PDF 导出

- 引入 `pdfkit`；`utils/pdfExport.ts`（**中文字体自动解析**：`simhei.ttf` / `simkai.ttf` / `Deng.ttf` 优先，可 `PDF_FONT_PATH` 环境变量覆盖；表格自动分页 + 表头重绘）。
- `GET /api/reports/exams/:id/export-pdf` **复用成绩导出的同一套列白名单**；前端导出弹窗新增 Excel / PDF 格式切换。

### 5.3 看板趋势与归因

- `GET /api/reports/dashboard`：**及格率时间趋势**（SQL 聚合，每人取最新一次已交卷）+ **按科目（知识点）错题归因**（简答题排除）。
- 前端「数据总览」页新增 ECharts **双轴折线图**（及格率 / 平均分）+ **科目错题率柱状图**。

## 10. 部署与升级步骤

1. **拉取代码**：切到 v1.6 提交（`75565a9` 或其后）。
2. **安装依赖**（新增 `pdfkit`）：
   ```bash
   npm install --ignore-scripts
   npm --prefix server install --ignore-scripts
   ```
3. **数据库升级**（幂等，直接对现有库执行即可，无需重建）：
   ```bash
   npm run db:init
   ```
   升级内容：扩 `questions.type` / `exam_records.status` ENUM、加 `exam_records.subjective_scores`、加 `departments.parent_id`、建 `bank_authors` / `audit_logs`。
4. **字体（仅 PDF 导出相关）**：默认自动探测 Windows 字体（`simhei.ttf` 等）。Linux/容器部署若无中文字体，需设置环境变量指向可用中文字体文件：
   ```ini
   PDF_FONT_PATH=/usr/share/fonts/truetype/xxx/xxx.ttf
   ```
5. **构建前端**：`npm run build`（产物 `dist/`）。
6. **菜单权限**：无需手工干预——存量 `menu_permissions` 会在初始化时自动合并新增菜单 key；未配置过的角色直接使用内置默认。
7. **冒烟建议**：出题人建一道填空题 + 一道简答题组卷 → 考生作答交卷 → 观察是否转「待阅卷」→ 管理员/出题人在「人工阅卷」给分 → 考生查看最终成绩；再验证成绩报表「切屏审查」与「PDF 导出」、数据总览趋势图、审计日志留痕。

## 11. 已知限制与注意事项

- **PDF 中文字体依赖**：非 Windows 环境（Linux/容器/CI）默认可能无 `simhei` 等字体，务必设置 `PDF_FONT_PATH`，否则中文可能显示为方框。
- **删题不回溯**：试卷/题库快照机制保证已开考答卷不受影响，但历史成绩明细按快照还原，修改题库不改变历史。
- **审计日志无外键**：这是刻意设计（操作者/目标删除后日志仍可读），因此 `actor_name / target_name` 为写入当时的快照值，不会随对象改名而更新。
- **简答题不参与错题率**：报表错题归因已排除简答，避免「恒错」污染统计。
- **限流/锁定持久化**：`login_attempts`、`rate_limit_buckets` 落库，多实例部署时无需额外共享存储。
- **红线**：所有脚本/测试仅针对 `enterprise_exam_system`（及测试库 `..._test`）；**严禁**操作同实例下的其他库（如 `exam_system`）。
