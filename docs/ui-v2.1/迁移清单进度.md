### 踩坑（已写成护栏）
原 `.el-table .el-table__cell { padding: 11px 0 }` **实际从未生效**：它与 Element Plus 自带规则
同优先级，被按样式注入顺序覆盖，真实内距一直是 EP 的 8px。第一版密度切换因此「点了没反应」——
变量从 11px 正确变成 7px，但行高纹丝不动。改为 `td.el-table__cell, th.el-table__cell` 提高一级后生效。
`globalStyle.test.ts` 已加断言锁住这个选择器写法。

同时把规范 §8.3 的行高从「48 / 40」修正为实测值「40 / 32」：原 48 是设计目标值，
而项目实际一直跑在 EP 默认的 40；本轮以实测为准，且舒适档保持 40 意味着**切换前视觉零变化**。

### 遗留决策落地（v2.2.1，2026-10-14）

用户确认「按你说的来」后，第 6 轮列出的两项遗留决策已执行。**仅动练题端**——管理端 `$color-secondary`（紫）
还兼作仪表盘统计卡强调色，且 §2.5 已将其列为分类色合法例外，故保持不动；练题端才是「严格单一蓝主色」约定方。

#### 1. 主色收口：一个工程不再有两个蓝

问题根源不在组件，而在 **Element Plus 主题**：`styles/element/index.scss` 的 `$colors.primary.base`
写着 `#2563eb`（管理端主色），而练题端自定义组件用 `$practice-primary`（`#1d4ed8`）——
于是 EP 按钮/选中态与自定义按钮呈现两个蓝。

| 项 | 修前 | 修后 |
|---|---|---|
| `element/index.scss` `$colors.primary.base` | `#2563eb` | `#1d4ed8` |
| `index.scss` `--el-color-primary` | `#2563eb` | `#{$practice-primary}` |
| `--el-color-primary-light-3/-5/-7/-8/-9` | `#60a5fa…#eff6ff`（按 blue-600 基色排） | `#3b82f6 / #60a5fa / #93c5fd / #bfdbfe / #dbeafe`（blue-500…100 阶梯，与 blue-700 基色同族） |
| `--el-color-primary-dark-2` | `#1d4ed8` | `#{$practice-primary-dark}` |
| `QuestionCard.vue` 16 处 `$color-primary*` | 管理端语汇 | `$practice-*` 家族 |
| `index.scss` 6 处 `$color-primary*` | 管理端语汇 | `$practice-*` 家族 |
| 业务层硬编码主色 3 处 | `rgba(29, 78, 216, …)` ×2、图表 `fill="#1d4ed8"` | `rgba($practice-primary, …)`、图表改用 CSS 类 + `$practice-primary` |

新增 `$practice-primary-light: #3b82f6` 补齐家族（原靠 `$color-primary-light` 顶替）。

#### 2. 多选题型去紫改青

`$color-secondary`（`#7C3AED`，violet-600）恰是「冷静蓝」明令禁止的紫。题型编码虽是 §2.5 的分类色例外，
但练题端约定更严，故改用青色分类 token：

| 题型 | 修前 | 修后 |
|---|---|---|
| 单选 | `$color-primary` 蓝 | `$practice-primary` 蓝 |
| **多选** | `$color-secondary` **紫** `#7C3AED` | `$type-multiple-text` **青** `#0E7490` + `$type-multiple-soft` `#ECFEFF` |
| 判断 | `$color-warning-text` 橙 | 不变 |

新 token 独立命名 `$type-multiple-*`（前缀标明「分类色」），与状态色分离，避免把「青」误当作 `info` 语义。

#### 3. 死 token 清理（12 个，引用数均为 0）

`$sidebar-*` 全套 7 个（练题端是底部 Tab，无侧栏）、`$gradient-brand`、`$header-height`、
`$shadow-card` / `$shadow-md`、`$radius-xl`、`$color-info-50`（与 `$color-info-bg` 重复）。
