# 管理端设计规范 v2.1（Design System · 冷静蓝商务风）

> 适用范围：管理端（登录 → 侧栏导航 → 数据总览 / 列表 / 表单 / 详情 全链路）。
> 配套高保真原型：[`admin-prototype.html`](./admin-prototype.html)（浏览器直接打开，含规格标注模式：**双击顶栏空白处**开启）。
> 设计原则：**单一主色、平铺浅底、细边框优先于阴影、小圆角、克制动效**。所有值经过 WCAG 2.1 AA 实测。

---

## 1. 设计原则（为什么这么定）

1. **一屏一个主按钮**：主操作唯一且高饱和，其余全部降级为次要/文字按钮，扫读时视线有且只有一个落点。
2. **细边框代替阴影划分层次**：同层元素用 1px `#E2E8F0` 描边区分；阴影只给「脱离文档流的浮层」（下拉/对话框/抽屉），同屏最多一个最高层级。
3. **信息密度服务效率**：企业后台用户是高频操作者，默认密度（行高 40）保证可读，提供紧凑模式（行高 32）给大表格场景。
4. **状态先于样式**：每个数据界面必须先定义 加载 / 空 / 无权限 / 出错 / 成功 五态，再谈视觉。
5. **符合既有习惯**：左侧分组导航 + 顶部面包屑、筛选区在列表上方、批量操作勾选后出现、危险操作二次确认——全部沿用企业后台惯例，不发明新交互。

### 2.5 分类色（题型编码）—— 唯一的多色相例外

主题装饰色严格单一主色（blue），但「题型编码」是**分类信息**：需要多个可区分色相帮考生一眼识别题型，属规范内唯一允许的多色相场景。

| 题型 | 色相 | 文字档 | 浅底 |
|---|---|---|---|
| 单选 | 蓝 | `$color-primary` | `$color-primary-soft` |
| 多选 | 紫 | `$color-secondary` | `$color-secondary-soft` |
| 判断 | 橙 | `$color-warning-text` | `$color-warning-bg` |
| 填空 | 绿 | `$color-success-text` | `$color-success-bg` |
| 简答 | 灰 | `$text-secondary` | `$color-table-head` |

- 用于「考试作答页」题型徽标与答题卡分组色点；**只做分类表达，不表达状态**（状态一律走 §2.3 三件套）。
- 徽标文字同样取**深色档**（原色对白底不达标），底取 `-bg` / `-soft`。
- 分类色**不得外溢**到列表页 / 表单页 / 侧栏等主题场景——那里只允许蓝色。

## 3. 字体排印

系统字体栈：`-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`（与 `styles/element/index.scss` 一致）。

| 用途 | 字号/字重 | 行高 |
|---|---|---|
| 页面标题 | 20 / 700 | 1.3 |
| 卡片标题 | 16 / 600 | 1.4 |
| 正文 / 表格 | 13.5 / 400 | 1.5 |
| 辅助说明 / hint | 13 / 400（n-500） | 1.5 |
| 标签 / 徽标 | 12 / 500 | 1 |
| 指标数值 | 28 / 700 | 1.2 |

- **两档字重原则**：正文一律 400，强调用 600；700 仅限页面标题与指标数值，避免满屏加粗。
- **数字统一 `tabular-nums`**：分数、条数、金额、时间在表格与指标卡中启用等宽数字，防止刷新跳动。

## 4. 间距与密度

4px 基准：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`。

| 场景 | 值 |
|---|---|
| 图标-文字间距 | 4~6 |
| 按钮组 / 标签组间距 | 8 |
| 表格单元格内边距 | 12（左右） |
| 卡片内边距 | 标准 20 / 紧凑 16 |
| 页面内边距 | 标准 24 / 紧凑 16 |
| 栅格间距 | 16（紧凑 12） |
| 区块之间 | 32（同组 16） |

**密度模式**（列表页右上角切换，记忆用户选择）：

| | 标准 | 紧凑 |
|---|---|---|
| 表行高 | 48 | 40 |
| 控件高 | 32 | 28 |
| 页面内边距 | 24 | 16 |

## 5. 圆角 / 阴影 / 动效

| 层级 | 值 | 用于 |
|---|---|---|
| r-xs 4 | `4px` | 骨架块、kbd |
| r-sm 6 | `6px` | 标签、徽标、分页按钮 |
| r-md 8 | `8px` | 按钮、输入、菜单项、开关轨道 |
| r-lg 10 | `10px` | 卡片、侧栏浮层 |
| r-xl 14 | `14px` | 对话框、抽屉 |
| pill | `999px` | 头像、chip、开关 |

阴影（**只用于浮层**）：
- `sh-sm` 卡片常态（极浅，可有可无，默认保留）
- `sh-md` 下拉菜单、用户菜单
- `sh-lg` 对话框、抽屉、侧栏折叠浮层

动效：交互反馈 150ms、展开折叠 200ms、缓动 `cubic-bezier(.4,0,.2,1)`；页面进入 = 150ms 淡入 + 4px 上移；**全部遵循 `prefers-reduced-motion`**。

## 6. 布局与栅格

```
┌──────────┬──────────────────────────────┐
│ 侧栏 232 │ 顶栏 60                       │
│ (折叠64) ├──────────────────────────────┤
│          │ 内容区 padding 24，自身滚动    │
└──────────┴──────────────────────────────┘
```

- 内容区 12 列，卡片按 2 / 3 / 4 等分；指标卡 4 列、图表区 2:1（≥1680 可 3 列指标）。
- 断点：≥1680 宽松 / **1440 基准** / 1280 图表改堆叠 / 1180–1279 筛选 3→2 列、表格横向滚动。
- 管理端不做手机适配，<1180 保持横向滚动保证表格可读（与现有 `min-width:1280` 策略一致，建议放宽到 1180）。

## 7. 侧栏与导航（含折叠态）

| 项 | 规格 |
|---|---|
| 展开 / 折叠宽 | 232 / 64（宽过渡 200ms） |
| 品牌区 | 高 60，与顶栏等高对齐；logo 实色 blue-600，**无光晕无渐变** |
| 菜单内边距 | 10（折叠 8） |
| 一级项 / 二级项 | 高 40 / 36，圆角 8，间距 2 |
| 图标 | 一级 18px，二级 15px，折叠态 18px |
| 选中态 | 底 `rgba(37,99,235,.24)` + 白字 600 + 左指示条 3×18（二级 3×16） |
| 折叠态选中 | 整块高亮，**隐藏指示条** |
| 二级缩进 | **二级图标左缘 = 一级文字左缘**（绝对 x≈53），文字 ≈78 |
| 分组 | 可折叠，手风琴式（同时只开一组）；当前页所在组默认展开 |
| 折叠态 | 图标水平居中（偏差必须为 0），悬停弹出深色浮层 min-width 168 / 行高 36 / 圆角 10 / sh-lg |
| 单项目分组 | 不套子菜单，折叠后直接显示为图标项 |

### 7.1 Element Plus 实现注意（踩坑记录）

1. `.el-menu--collapse` 与自定义菜单类**在同一元素**上，SCSS 必须用 `&.el-menu--collapse` 连接，后代选择器永不命中。
2. 折叠态 `el-menu-item` 内容被包进 `.el-menu-tooltip__trigger`（绝对定位 + 自带 `padding: 0 20px`），**必须同时重置该层**，否则图标右偏约 8px 无法居中。
3. 折叠态文字占位会把图标挤偏（实测 -19~-20px）：文字须收起（EP 自动处理 title 槽；自绘菜单需显式 `display:none` 或 `font-size:0`）。

## 8. 组件规范（状态矩阵）

### 8.1 按钮（高 32 / sm 28 / lg 40，圆角 8，内边距 0 14）

| 类型 | 常态 | hover | 用途 |
|---|---|---|---|
| Primary | blue-600 底白字 | blue-700 | 每屏唯一主操作 |
| Default | 白底 + n-200 边 | n-50 底 + n-300 边 | 次要操作 |
| Text | 无底蓝字 | blue-50 底 | 行内/低强调操作 |
| Danger-text | 无底 `#B91C1C` 字 | error-bg 底 | 删除等危险行内操作 |
| Danger | error 底白字 | `#B91C1C` | 对话框内确认危险操作 |

规则：危险文字按钮**不与主按钮相邻**；禁用 = 50% 透明 + not-allowed；加载态保留按钮宽度防跳动。

### 8.2 输入（高 32，圆角 8）

| 状态 | 表现 |
|---|---|
| 默认 | 白底 + n-200 边 |
| hover | n-300 边 |
| focus | blue-600 边 + `0 0 0 3px rgba(37,99,235,.12)` 外圈 |
| 错误 | `#DC2626` 边 + 红色外圈 + 下方 12px 错误文案（`#B91C1C`） |
| 禁用 | n-50 底 + n-400 字 |

规则：占位符用 n-500（不用 n-400，对比不足）；错误信息**说怎么改**，不只说「无效」。

### 8.3 表格

- 表头：高 40、底 n-50、13px/500 n-600 色；行高 40（紧凑 32，切换入口在列表页工具条右端），行 hover n-100，选中行 blue-50。
- 数字列 `tabular-nums`（已全局覆盖，见 §11）；对齐约定：存量项目以 `align="center"` 为主（57 列）、`right` 7 列——**center + 等宽已满足可读性，不做大规模翻转**；新增页面若列内数字需要量级比较（金额/得分/时长），优先 `right`。操作列右对齐固定；列宽策略：题干/名称类弹性，枚举/时间/数值定宽。
- 批量操作：勾选后顶部滑出蓝色条（blue-50 底 + blue-200 边），显示「已选 N 项 + 批量动作 + 取消选择」。
- 分页：右对齐，「共 N 条 + 每页条数 + 页码 + 跳页」，默认 20 条/页。

### 8.4 标签（高 22 / 圆角 6 / 12px）

`未开始`(中性) / `进行中`(primary+圆点) / `已交卷`(success) / `待阅卷`(warning) / `异常`(error) / `已结束`(info)。颜色一律用 2.3 三件套，**不得**用语义原色作文字。

### 8.5 反馈层级

| 层级 | 组件 | 场景 |
|---|---|---|
| 打断 | 对话框（宽 520，圆角 14） | 不可逆操作确认，正文说后果，附影响范围 |
| 侧栏细节 | 抽屉（宽 480） | 行内「详情」，不打断列表上下文 |
| 轻提示 | Toast（顶部居中，2.4s） | 操作成功/失败的一次性反馈 |
| 常驻说明 | Alert（四语义） | 页面级解释、预警，可关闭 |

## 9. 页面模板与用户习惯约定

### 9.1 数据总览
页头（标题 + 数据时间说明 + 导出/新建）→ 指标卡 ×4（标签 13 / 数值 28 / 环比 12 + 迷你趋势）→ 图表区（2:1，图表卡片带时间范围 chip）→ 待办列表（状态标签 + 时间 + 行内操作）→ 最近考试小表。

### 9.2 列表页
筛选卡（4 列栅格，label 上置 13px n-500；快捷 chip 一行；底部固定「重置 / 查询」）→ 批量条（勾选后出现）→ 表格卡（标题 + 计数 + 密度切换）→ 分页。
**习惯约定**：查询按钮在右下固定位置；重置同时清 chip 与表单；空态给「清空筛选 + 主操作」双出路。

### 9.3 表单页
步骤条（数字圆点 + 连线）→ 顶标签布局（label 上置，长文案友好）→ 右侧辅助栏（「为什么需要这些设置」+「发布检查」清单）→ **sticky 底部操作条**（取消 / 保存草稿 / 下一步主按钮）。
规则：必填标 `*` 红色；帮助文本常显（不藏在 hover）；错误就地显示且聚焦第一个错误项。

### 9.4 详情页
页头（名称 + 状态标签 + 关键元信息 + 导出/详情/危险操作）→ 指标条 ×4 → Tabs（概览/名单/分布/异常/日志）→ 描述列表（3 列 dl）+ 时间线（左侧 1px 线 + 圆点）。

## 10. 可访问性要求（验收硬性项）

- [ ] 正文对比度 ≥ 4.5:1；大字/图形 ≥ 3:1（对照 §2.4 表，禁止 n-400 作说明文字）
- [ ] 全站可见焦点环：`:focus-visible` 2px blue-600 + 2px offset
- [ ] 键盘可达：Tab 顺序 = 视觉顺序；Esc 关闭浮层；对话框聚焦陷阱
- [ ] 触达目标 ≥ 32×32（图标按钮 32×32，折叠按钮带 title + aria-label）
- [ ] 状态不用颜色单一表达：标签带文字、圆点仅辅助
- [ ] 动效遵循 `prefers-reduced-motion`
- [ ] 表单控件显式关联 label（`for`/`id`），错误信息 `aria-describedby`
