# v3.1 方向对比 · 三套「蓝色主色 + 深色侧栏」

> 打开 `index.html`，底部控制台一键切换 **方向（A/B/C）× 页面（5 页）**，同一套页面换三套 token，苹果对苹果比较。
> 地址栏支持 `#方向/页面` 直达，如 `#c/dashboard`。

## 为什么是这三套

上一版「卷面」被否的四点：纸墨复古感重、墨黑沉闷、直角实线太硬、精致度不够。
三套方向都锁死在「蓝色主色 + 深色侧栏」内，拉开的是**密度、圆角、层次手法**三个轴，全部避开上述四点。

| | A · 清透蓝 | B · 磐石蓝 | C · 精密蓝 |
| --- | --- | --- | --- |
| 一句话 | 白底大留白，轻而透 | 冷灰蓝底，稳而实 | 发丝线紧凑，密而准 |
| 主色 | `#2563EB` blue-600 | `#1D4ED8` blue-700 | `#0B5BFF` 电光蓝 |
| 页面底 | `#F6F7F9` 近白 | `#F2F4F8` 冷灰蓝 | `#F7F8FA` 中性 |
| 卡片 | **无边框 + 柔和投影** | 细边框 + 极轻投影 | 发丝线 + 零投影 |
| 圆角 | 14 / 9px | 10 / 7px | 8 / 6px |
| 行高 | 50px（呼吸感） | 44px（均衡） | 38px（高密度） |
| 侧栏 | 深海军蓝 `#0E1726`，胶囊选中 | 深蓝 `#12294A`，**左侧指示条** | 石墨 `#0B0F19`，紧凑 + 圆点 |
| 表头 | 无底色，仅下墨线 | 浅灰底 | 大写字距标签 |
| 悬停反馈 | 面变浅灰 | 面变浅灰 | 面变浅灰 + **左侧蓝条** |
| 适合 | 对外演示、年轻团队、内容型 | 企业正式考核、领导审阅场景 | 题量大、页面信息密集的日常运营 |

## 可访问性（WCAG AA 实测）

全部文字档 ≥ 4.5:1，图形档（`--icon`）只允许用于图标/装饰：

| 档位 | A | B | C |
| --- | --- | --- | --- |
| 正文 `--text-1` | 16.0 | 15.6 | 17.9 |
| 次要 `--text-2` | 8.35 | 8.75 | 10.3 |
| 弱文字 `--text-3` | 4.97 | 5.60 | 5.98 |
| 主色（白字按钮/文字） | 5.17 | 6.70 | 5.31 |
| 侧栏弱文字 | 8.58 | 7.17 | 7.70 |
| 语义色文字 `*-t` | 5.41~6.57 | 同 | 同 |

**红线**：`--icon`（约 2.5:1）只作图形色，禁止承载文字；语义原色不作文字色，一律用 `*-t` 档——沿用 v2.2 色彩合规铁律。

## 共同的精致度底线（三套都遵守）

- 4px 间距栅格；数字一律 tabular-nums，无衬线（上一版的衬线数字已废弃）。
- 层次只用「边框 / 投影 / 底色」其中一种主导，不叠加堆砌。
- 状态徽章统一「浅底 + 深字 + 圆点」三件套，全套沿用 v2.1/v2.2 规范语义。
- 批量操作用蓝色实底浮动条（选中后滑出），不做工具条灰化按钮。
- 空态区分「筛选无结果 → 清空筛选 + 主操作」与「真无数据 → 仅主操作」。

## 落地成本（任选一套）

| 步骤 | 工作量 |
| --- | --- |
| 1. 替换 `variables.scss` token 区块 | 半天 |
| 2. Element Plus 主题层 `$colors.primary.base` 同步主色 | 10 分钟（不做会出现两个主色，v2.2 踩过） |
| 3. 圆角/行高/阴影变量切换 | 2 小时 |
| 4. `styleGuard.test.ts` 新增断言（主色唯一 / icon 禁作文字 / 圆角档位） | 半天 |

三套 token 结构完全同构，**选定后切换成本一致**；B 与现有 v2.2 差异最小，A 观感最现代，C 信息效率最高。

## 建议

先在真实工程里把三套 token 各切一次看整站观感（改 2 个文件即可），再定稿。若要我直接推荐：**管理端日常高频是表格与表单，B（磐石蓝）在「稳重可信」和「不沉闷」之间最平衡**；如果更看重对领导/对外展示的观感，选 A。
