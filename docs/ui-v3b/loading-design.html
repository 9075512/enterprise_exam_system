Loading 加载设计方案（5 选 N）

统一沿用「方向 C」视觉语言：唯一主色 #0B5BFF、发丝线描边、8/10px 圆角、无投影。每个方案标注了适用场景，可单选也可组合成一套「分场景加载体系」。

考
EXAM CENTER
① 品牌徽标脉冲 全屏

「考」徽标呼吸缩放 + 双层进度环反向旋转 + 字距拉开的品牌字。深底适配，仪式感最强。

适用：登录后首屏、首次进入考试（冷启动 > 800ms 的场景）

② 三点波 局部

三点错相上跳 + 透明度递减，体量最小，不打断视线。

适用：按钮提交中、卡片内局部刷新、表格翻页等待

③ 骨架屏 页面级

按真实版式占位 + 高光扫过，内容"未到先知"，感知等待时间最短。

适用：列表页、报表页、成绩明细等结构稳定的页面

④ 环形进度 确定进度

圆角端点环形进度 + 中央百分比。呼吸动画示意"仍在推进"，有真实进度时换成精确值并停用动画。

适用：Excel 批量导入、试卷生成、人工阅卷保存

⑤ 顶栏进度细条 路由级

3px 主色渐变细条从左向右冲刺循环（NProgress 式），用户几乎注意不到却知道"在走"。

适用：路由跳转、菜单切换的全局过渡（全站只挂一处）

推荐组合（分场景体系，而非全站单一 spinner）

⑤ 顶栏细条挂路由守卫（全站默认）→ ③ 骨架屏替换现有列表页 LoadingSkeleton（已具备，仅统一动效）→ ② 三点波用于按钮与局部 → ① 品牌脉冲仅在登录/开考前全屏 → ④ 环形进度留给导入/判分等有进度的异步任务。全部纯 CSS 动画，无 JS 依赖，动画时长统一 1.1–1.8s（长于感知阈值、短于焦虑阈值）。
