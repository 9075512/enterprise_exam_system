使用说明

  • 想要一个文件看全站：打开 report.html · 单文件报告——39 页全部内嵌，左侧目录 + 上/下页切换 + 点页面内卡片直接跳转，最适合在预览面板里翻看。
  • 点击任意卡片打开该页设计图；每页右下角有 ◱ 全部页面 与上/下页按钮可连续翻看。
  • 页面为零依赖单文件 HTML——样式与脚本已全部内联，双击即可打开，无需起服务；单个文件发给别人或放进预览面板也不会丢样式。
  • 侧栏、顶栏、面包屑由 kit/shell.js（源文件）按 data-page 自动注入，页面文件只写内容区；改 kit/ 源文件后重跑 node tools/inline-kit.mjs 即可刷新全部页面。
  • 练题端由 kit/mshell.js 包 390×800 手机外框，底部四 Tab 与真实路由一致。
  • 部分页面内置「空态 / 未作答态 / 表单态」等状态演示块，用于交付时说明边界场景，不代表页面默认形态。
  • 配色与落地映射见 设计系统页 与 DESIGN-C.md；三方向对比稿保留在 compare-abc.html。
