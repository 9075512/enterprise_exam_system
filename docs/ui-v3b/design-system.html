§3

语义色三件套

铁律：原色只作图形与描边，文字一律用 -t 档（700 档，≥4.5:1）

语义原色（图形）浅底描边文字 -t 档对比度示例
success #12B76A #ECFDF3 #A6F4C5 #027A48 5.41:1 ✅ 及格 / 已通过
warning #F79009 #FFFAEB #FEDF89 #B54708 5.43:1 ✅ 待审批 / 阅卷中
error #F04438 #FEF3F2 #FECDCA #B42318 6.57:1 ✅ 未及格 / 已驳回
info #2E90FA #EFF8FF #B2DDFF #175CD3 5.99:1 ✅ 考试通知

反例：#F04438 直接作文字仅 4.02:1，不达 AA；语义原色只允许出现在图标 stroke、圆点、进度条填充、描边上。

§4

层次手法 · 三条铁律

这是 C 方向与 v2.2 最本质的差别

① 线条优先

no shadow

卡片 = 白底 + 1px --line，零投影。需要强调层次时加深线条（--line-strong），不许加阴影。阴影让界面「飘」，线条让界面「稳」。

② 左缘蓝条做行级焦点

signature

表格行 hover / 当前记录 → inset 2px 0 0 var(--primary)。替代整行变色，扫读时定位更精准。下方可实测。

③ 蓝色只表达「可操作」

semantics

链接、按钮、选中态、批量条。状态一律走语义色；题型分类色（如「多选」青）是唯一例外，不外溢到列表与侧栏。
