# 核心功能升级部署说明

本次升级补充题库（科目）与组织权限、考试冻结名单和准考证、题库质量治理、练题监控，以及五项考试规则。其中科目即题库名称，不单独维护第二套目录。升级不包含考试报名管理。

## 升级前

1. 停止管理端、考试端和练题端写入流量。
2. 备份业务数据库，并确认可以恢复。
3. 保存当前服务端环境变量和公网练题数据库账号授权。
4. 使用项目当前要求的 Node.js 与 MySQL 版本安装依赖。

## 数据库升级

在项目根目录执行：

```powershell
npm install
npm --prefix practice-web install
npm run db:init
```

`db:init` 为幂等升级，可重复执行。它会：

- 建立岗位、用户组、数据授权、模板、考试人员、题目反馈和练题会话表；
- 为用户、试题、考试和答卷补充兼容字段；
- 将存量试题的 `subject` 统一回填为所属题库名称，`subject_id` 统一回填为 `bank_id`；
- 将试卷题目外键调整为禁止级联删除，保护历史试卷引用。

升级后应核对原用户数、题库数、试题数、试卷数、考试数和答卷数，确认业务数据数量未减少。

## 公网练题最小权限

由数据库管理员执行 [db-grants-practice.sql](../deploy/db-grants-practice.sql)，按实际库名、账号和来源主机替换脚本中的占位值。新版本额外需要：

- `practice_sessions`：`SELECT`、`INSERT`、`UPDATE`；
- `practice_session_answers`：`SELECT`、`INSERT`；
- `question_feedback`：`SELECT`、`INSERT`。

公网练题账号不应获得考试答卷、系统设置或后台管理表的写权限。

## 构建与校验

```powershell
npm run typecheck
npm run test
npm run build

npm --prefix practice-web run typecheck
npm --prefix practice-web run test
npm --prefix practice-web run build

npm --prefix server run typecheck
npm --prefix server run test
npm --prefix server run build
```

部署顺序建议为：数据库升级、服务端、管理与考试前端、公网练题前端。服务端就绪后再恢复入口流量。

## 上线后检查

- 管理员能进入科目管理、组织扩展、模板管理、题目反馈、重复题审计和练题监控。
- 新建考试保存后能看到冻结名单，重复导出的准考证号保持不变。
- 停用题不会进入新组卷、每日一练和普通练题。
- 练题监控能收到实时数据；阻断 SSE 后约 15 秒进入轮询模式。
- 切换匿名阅卷、成绩明细、补考取分和异常退出策略后，服务端行为与设置一致。

## 回滚

应用代码可以回滚到升级前版本；数据库结构应保留，不要直接删除新增表或字段。若必须完整回滚数据库，请在停写后恢复升级前备份。升级过程不会自动重算已经提交的历史答卷。
